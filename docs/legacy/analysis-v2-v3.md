# Analysis — revised protocol

Question: Does a brief reminder of the last submitted check improve behavioral resumption after a standardized interruption during order checking? Everyone completes A (uninterrupted), B (secondary task, no card), and C (same secondary-task procedure, last-submitted card) using different matched task sets. The C–B comparison estimates the net effect of the card, including visual presence, reading time and attention guidance; it does not isolate information content.

| Comparison | Planned interpretation |
|---|---|
| C versus B, primary | Appropriate-next-check selection latency, with first-action sequence errors and subsequent judgment performance alongside it |
| B versus A | Interruption effects on active task time and accuracy |
| C versus A | Descriptive relative performance; nonsignificance does not demonstrate equivalence or full restoration |

These timings are behavioral performance measures. They are not cognitive load, pure memory retrieval time, or general workplace productivity. Selection alone does not establish complete recovery. First-submission timing may concern the wrong category; retain category and correctness. Expected-check submission timing reveals delay or incorrect judgment after early selection. Subjective workload is a separate outcome. Do not adjust the default performance comparison for post-condition workload, and do not condition collecting or analyzing C on B first being significantly worse than A.

Participants are independent sampling units; interruptions/orders are repeated observations. Preserve episode-level data for paired/repeated-measures analysis. Finalize handling of skew, missingness, censoring, multiplicity and technical deviations before inspecting main effects. No winner labels, significance-based stopping, arbitrary latency penalties, or trimming valid long responses. Report observed, unobserved and not-applicable counts beside summaries. Repetition is descriptive; it may reflect deliberate verification.

Counterbalance condition and task-set order independently using the existing seeded 36-slot cycle. Never recycle abandoned slots or regenerate assignments. Report allocation, attrition, exposure and completion balance. Counterbalancing does not remove strategy carryover; document prior main cue exposure and universal demonstration exposure. X/Y/Z structure, code lengths, mismatch patterns and packaging demands are matched by construction; equal human difficulty still requires pilots.

Accuracy uses final judgments across all required categories, omissions incorrect, and separately retains first judgments and their denominator. Revised started-block summaries have 48 required categories, plus exposed-order/category counts. An incomplete block is clearly marked and has null full-block time; do not confuse unexposed required records with observed responses. Original v1 completed-order denominators remain unchanged in legacy summaries.

A invisible checkpoints yield ordinary transition times, exported separately. Do not automatically subtract them from B/C to claim pure cognitive processing. Active time subtracts the union of actual secondary-screen intervals and recorded pauses; recovery remains included. Item exposure and engagement are observations, not evidence of equal internal workload. Do not selectively remove low-engagement participants after viewing effects.

Use explicit annotation review for technical concerns. Optional clean sensitivity tables retain their predefined technical/prior-sequence flags and never replace unfiltered tables. Protocol versions remain separate. Preserve withdrawal and documented retention policies. No retrospective exclusion solely for poor main-task performance.

| Alternative explanation | Control | Remaining limitation |
|---|---|---|
| Button search | Four fixed visible controls, shared layout and training | Timings still include visual and motor processing |
| Layout/focus shift | Reserved card space; same records, control positions and focus policy | Card attracts attention and takes time to read |
| Correctness mistaken for resumption | Separate selection, submission and judgment metrics | No timing metric identifies a psychological mechanism |
| Unequal secondary engagement | Fixed timing/procedure; matched forms; item exposure and omissions | Internal workload can differ between people |
| Prior sequence deviations | Actual history retained; frozen expected category; descriptive flags | Strategy/verification can explain repetitions |
| Practice/carryover | Universal A/B/C demonstration and independent counterbalancing | Learning can persist across configurations |
| Timing artifacts | Monotonic segments, frame-aware readiness, interval components and flags | Browser timestamps are not hardware onset measurements |
| Clear baseline has little difficulty | Silent pilots assess floor/ceiling effects | May need a study-design discussion, never a deliberately worse UI |

Relevant background: [Trafton, Altmann & Brock (2005)](https://doi.org/10.1177/154193120504900354), environmental cues after interruption.
