# Raw TLX administration — raw-tlx-1

Verified 2026-10-30 against the [official NASA TLX page](https://www.nasa.gov/human-systems-integration-division/nasa-task-load-index-tlx/) and NASA's [rating scale sheet](https://human-factors.arc.nasa.gov/groups/TLX/downloads/TLXScale.pdf). Exact item questions and endpoint labels are versioned in `server/questionnaire.py` and copied into every revised manifest and item export. NASA permits use and modification of the tool. The scale sheet contains six dimensions despite its introductory reference to five scales; this application uses all six.

The [NASA iOS user guide](https://www.nasa.gov/wp-content/uploads/2026/01/nasa-tlx-for-ios-user-guide-final.pdf) also documents an unweighted study option and deliberate scale responses. [Hart (2006), NASA-Task Load Index: 20 Years Later](https://www.nasa.gov/wp-content/uploads/2026/01/hfes-2006-paper.pdf), methodological issues, describes removing pairwise weighting and combining ratings for Raw TLX. The supplied [primary control-room study](https://www.sciencedirect.com/science/article/pii/S0169814119302847) was consulted through its indexed publisher excerpt describing the unweighted global score; its full page returned HTTP 403. Hart's accessible primary paper is the methodological basis here. The original paper-and-pencil manual download did not resolve in this environment; do not claim it was fully reviewed.

Administration is after each entire block, including interruptions where present, before the fixed break. Order: Mental Demand, Physical Demand, Temporal Demand, Performance, Effort, Frustration, then separately labeled exploratory tracking. Each empty numeric input requires an intentional response, 0–100 in increments of 5 (21 available scores); there is no default midpoint. The application uses a numeric digital input rather than replicating the paper ruler. This is an explicit implementation choice requiring pilot review, not a validation claim.

For Performance, **0 = Perfect; 100 = Failure**. Displayed responses already have low-to-high workload orientation. `oriented_score = displayed_response` for every dimension; no reversal is applied. Raw TLX is the arithmetic mean of the six oriented TLX ratings, with equal weights and no pairwise weighting. All six valid responses are necessary. Missing or incomplete questionnaires have null aggregates, even if draft item responses are available. Item changes and final submissions are retained. The extra tracking rating is excluded from this mean and is not independently validated.

## raw-tlx-2 (pilot-3)

Same six TLX items, order, wording, endpoint labels, keys, 0–100 values in steps of 5, identity orientation and Raw TLX mean as `raw-tlx-1`. Only administration changes: each item is answered by clicking one of 21 marks on a horizontal scale (taller middle mark, endpoint labels, no numerals), mirroring the scale-sheet layout instead of typing a number. No mark is preselected; Save is enabled only when all seven items are answered. The exploratory tracking question keeps its wording and is shown after the TLX items under the title “Keeping track”. Each click is logged as `questionnaire_item`, as before. This administration still needs pilot review and is not a validation claim.

The standalone `custom-workload-1` records retain their original labels, 1-point resolution and definitions; no historical TLX is fabricated. Questionnaire values do not enter allocation, task difficulty, later instructions or interruption scheduling. Recognizing an instrument does not validate this digital administration or establish a psychological mechanism.
